# Aymard Plakoo – portfolio

Site statique d'une page (FR/EN), publié avec GitHub Pages : <https://aymardino.github.io/portfolio_aymard/>

- `index.html` : la page (HTML, CSS et JavaScript, sans étape de build)
- `img/` : photo du congrès AISESA (© AISESA), captures des trois projets en ligne, image d'aperçu pour les réseaux
- `fonts/` : Roboto (licence Apache 2.0), hébergée ici pour n'envoyer aucune requête à un tiers
- `pdf/` : dossier de présentation de 3 pages, en français et en anglais

Static one-page portfolio (FR/EN) served by GitHub Pages. No build step, no third-party requests.
